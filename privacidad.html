Política de privacidad / Privacy Policy

Última actualización: 19 de noviembre de 2026.

Qué es Fabrica Canales

Es una herramienta de uso exclusivo de su propietario para subir vídeos a sus propios canales de YouTube y consultar las estadísticas de esos canales. No da servicio a terceros.

Uso de los Servicios de API de YouTube (YouTube API Services)

Fabrica Canales usa los Servicios de API de YouTube (YouTube Data API v3 y YouTube Analytics API). Al usar esta herramienta aceptas las Condiciones de servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de privacidad de Google.

Qué datos se usan

  • Permiso de Google (token OAuth) para subir vídeos y leer estadísticas de los canales del propietario.
  • Datos de los vídeos propios ya subidos (identificador y descripción), para evitar subidas duplicadas.
  • Estadísticas agregadas de los vídeos propios (visualizaciones, retención, «me gusta»).

No se recogen datos de espectadores ni de otras personas o canales, no se usan cookies y no se venden ni ceden datos a nadie.

Dónde se guardan y durante cuánto tiempo

Los tokens se guardan cifrados como secretos privados del propietario en GitHub Actions. Las estadísticas agregadas se guardan en un repositorio privado del propietario y se actualizan cada semana.

Cómo se borran los datos

  • Los datos obtenidos de la API de YouTube se eliminan o actualizan como máximo cada 30 días, salvo las estadísticas agregadas propias que el propietario decide conservar.
  • Puedes solicitar el borrado de todos los datos almacenados escribiendo al correo de asistencia que aparece en la pantalla de autorización de Google; se eliminan en un plazo máximo de 7 días.
  • Al revocar el acceso, los tokens dejan de funcionar de inmediato y se borran del almacenamiento.

Cómo retirar el permiso

El acceso puede revocarse en cualquier momento desde la página de configuración de seguridad de Google (permisos de terceros).

Contacto

Mediante el correo de asistencia que aparece en la pantalla de autorización de Google.
